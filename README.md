# evelynf082.github.io

My personal homepage — built from scratch with HTML, CSS, and JavaScript.

**Live site:** https://evelynf082.github.io

## About

A single-page site with sections for About Me, Research Interests, Projects,
and a personal blog, plus individual pages for each project and post.

## Built with

- HTML, CSS, and vanilla JavaScript (no frameworks)
- Hosted on GitHub Pages

## Structure

- `index.html` — the main homepage
- `project-*.html` / `post-*.html` — individual project and blog pages
- `css/` — styles
- `js/` — interactivity (scroll effects, nav dropdown)
- `images/` — photos
- `documents/` — embedded PDFs
